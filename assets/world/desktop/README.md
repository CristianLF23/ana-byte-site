# Ana Byte desktop city artwork

Four original panoramic scenes for the V1 desktop journey. Created on 23 September 2026 with the built-in image generation tool using Ana Byte's existing project illustrations as visual references. The real tattoos and photographs remain separate DOM/media assets; they are not embedded in these generated city backgrounds.

The WebP files retain the native pixel dimensions and are encoded at quality 84. The source PNGs are preserved beside the site repository, outside the published GitHub Pages package, in `../../../../ana-byte-desktop-masters/`. Responsive `<picture>` elements select the desktop or mobile artwork without downloading both versions of a scene. The four desktop WebP files total about 1.47 MB. The generated result is 1672 pixels wide, so it is native-size on ordinary laptop screens and necessarily softer on 4K monitors. Do not label an interpolated enlargement as 4K source art.

## Prompt record

- City: extend the approved rainy, elevated Ana Byte city view into a unified widescreen scene. Preserve canyon/bridge geography, a small rooftop cat, wet industrial structures, flying traffic, sparse cyan/magenta neon and a darker calm center for the HTML title.
- Works: move closer within the same district to an architectural billboard. Keep a black empty screen for real DOM content, thick wet metal, magenta/cyan neon tubes, a realistic tuxedo cat on its crown, rich surrounding city and no generated tattoo imagery.
- Artist: step right to an atelier building in the same district. Use a frontal wide empty billboard for the real artist photograph/text, heart-shaped biomechanical luminous ornament, matching facade materials and city lighting.
- Contact: rise to a panoramic view beside an illuminated katakana sign with original stylized biotech motifs and a tuxedo cat. Reserve a dark calm region on the right for the actual HTML invitation.

Each generation used a project-owned portrait scene as one visual reference, plus the preceding/generated panoramic city scene for continuity. The built-in image tool returned native PNG; the WebP copies were converted in browser Canvas without resizing.
